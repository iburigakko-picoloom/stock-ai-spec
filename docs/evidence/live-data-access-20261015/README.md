# 新規データ取得の接続確認

2026-10-15 JST。既存のprocess環境にAPIキーが存在することだけを確認し、認証値を表示・記録せず、公式V2へ2回の読み取り要求を行った。株価のBulkファイル一覧と、Free対応の銘柄一覧の両方がHTTP403。配当の一覧要求は基本要求の失敗を受けて実施していない。

原因を契約プラン・キー失効・回線制限のいずれかに断定しない。現在の接続で最新データを取得できる証拠はなく、再取得成功までは既存の保存データを「最新」と表示しない。契約・認証情報・catalog・production dataは変更していない。応答本文、APIキー、ダウンロードURLは証拠へ含めない。

ユーザーには管理画面での契約プランとキー有効状態の確認を依頼した。保存済みデータでの比較・source identity照合・アプリ実装は継続可能であり、Goal全体の停止理由とはしない。

次の会計接続に関する仕様確認（同日確認）:

- [公式プラン別データ仕様](https://jpx-jquants.com/ja/spec/data-spec)では、配当金情報はPremium向け。これは現在の本人の契約プランを確認した証拠ではない。
- [公式配当仕様](https://jpx-jquants.com/ja/spec/fin-dividend)は、予想と決定、通知の訂正・削除、権利日、支払予定日を区別する。PubDate/PubTimeをJ-Quantsでの取得可能時刻と同一視せず、PayDateを本人の口座への実入金確認にも置き換えない。サービス側のデータ修正については訂正前の版が提供されない場合が残る。

財務サマリーの配当額だけで権利/支払イベントを生成しない。新規取得や別の認証済みイベント入力がそろうまで、企業行動と実市場NAVの完全性は未確認のまま。今回の確認は成績評価・holdout採点・実注文を行っていない。
