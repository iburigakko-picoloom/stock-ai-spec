## 実装した範囲

実受領済みのJ-Quants上場銘柄一覧からCore30/Large70/Mid400の対応国内普通株を採る。今回の保存版は493銘柄で、500への補充や売買代金上位300への再選別はしない。全保有を追加し、非対応・履歴不足を理由付きで扱う。今回予測できたのは489銘柄、履歴不足は4銘柄。

月次の不変リストと観測した構成変更の版に、理由・規模・実受領時刻・適用時刻・出所・差分・hash・規則版を保存する。当日所属を認証できるmasterがない場合は停止する。月末の翌営業日情報も、公式の提供目安だけから入手済みと推定しない。

原本の日別圧縮batchは保持し、別の再生成可能tableに全市場の共通統計と対象銘柄別の価格履歴を保存する。再利用時は全市場の長期価格/masterを展開しない。通常追加日は直近の全市場情報から同じ計算式で共通統計を更新する。訂正・分割・新しい対象・コード/schema変更は保守的に再構築する。

初回・再構築は全市場価格の展開が残る。初回まで完全な日別stream処理に移行したとは扱わない。財務は原本検証後の対象日次結合へ限定するが、小さな財務・暦・TOPIX原本は再計算時に引き続き読む。現在の実モデル2回帰headは銘柄別推論で、集合内の順位正規化を追加しない。
