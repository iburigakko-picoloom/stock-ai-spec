# 同一foldの大幅下落確率・下側分位点比較

実18候補とtrain内発生率・経験分位点・V0 Logistic(C1)を同じOOFで比較。5日1,327,530行/6fold、20日1,044,317行/5fold。

全18候補の確率・分位点指標は前回の認証済み診断と完全一致。既存の回帰比較も同じキー・予測であることを再照合した。
大幅下落の閾値は両期間とも-8%、下側分位点はalpha=0.1。各候補の元設定を使用した。

5日・20日それぞれの9候補すべてが、Logisticとtrain内発生率よりBrier/log lossが低く、train経験分位点よりpinball lossも低かった。ただし10bin ECEは全18候補がtrain内発生率より高い。確率の当たり方を表す指標が改善しても、確率の数値そのものの較正が済んだとは判断しない。これらは同じ開発OOFの点推定比較であり、有意差や実用採用の証明ではない。

10%分位点を下回る実測割合は、5日の候補で約8.50〜9.14%、20日で約9.07〜11.08%。学習したensembleや後段の較正は別の時系列評価で検証する。
