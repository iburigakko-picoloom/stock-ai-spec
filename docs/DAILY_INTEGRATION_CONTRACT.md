## 共通インターフェース

| 境界 | 再利用する正本 | 固定する情報 |
| --- | --- | --- |
| 市場データ | immutable source manifest / `MarketReceipt` | provider、原byte hash、観測/公表/取得/訂正時刻、価格基準、対象期間・銘柄、利用権限 |
| 原予測 | `PredictionSnapshot` / development OOF | horizon、意味と単位、as_of/data_as_of、モデル/特徴量/データ版、元予測hash。順位scoreは無単位としreturnへ変換しない |
| モデル成果物 | campaign / `AdvancedResearchReport` / frozen feature selection | family・seed、順序付き特徴量、fold前処理、train/validation期間、code/data/hash、OOFと推論用weightの有無、holdoutアクセスの証拠範囲 |
| 口座 | `PortfolioState` + manual/settings revision | snapshot ID/hash、本人入力時刻、口座別株数・利用可能/予約現金、費用/税/リスク制約。口座番号・認証情報は外部用射影へ含めない |
| 評価 | content-addressed audit / NAV receipt | 評価区分、固定ルールhash、全候補と対象キー、原入力hash、費用・配当・税・約定仮定、実測時間、保留理由 |

③は固定manifestの読取専用入力を使う。②の更新は新しい版として公開し、評価中の入力を書換えない。①の完成や個人口座の未入力を③の研究比較の前提にしない。同一file/DB移行の編集責任者はmain agent。単一学習worker・CPU/RAM guardを維持する。

## 評価区分と選定

1. 予測精度の研究評価：既存18候補のpurged walk-forward/複数seedを維持し、5日/20日を別々に比較する。
2. 配当を含まない価格ベースの費用控除後研究評価：研究用資金・銘柄数・均等配分・単元・保有/入替・予測より後の約定時刻・費用・受渡しを成績確認前に固定する。欠損/約定不能を除外して成功にしない。価格履歴やPITの制約は明記し、採用証拠に昇格しない。
3. 配当込み評価：権利・決定/予想・入金、分割/併合等を含む網羅性が揃うまで保留。未知配当を0としない。
4. 個人税引後評価：本人snapshotと税policy/入金時刻が揃ってから別工程。既存税会計部品は保全するが②の開始を待たせない。

D166：既存の実市場NAV接続も`evaluation_tier=price_only_research`を明示できる。配当を加算せず、配当イベントの混入を拒否し、成功/停止receiptへ「配当を除外、ゼロ確認ではない」と記録する。分割/併合・現金交付・その他権利の確認は残し、狭い確認範囲を配当込み評価へ流用しない。旧入力の既定は従来の配当込み。詳細は[実市場NAV接続](REAL_MARKET_NAV.md)。この区分の実装を、実データの運用比較や最終採用の完了とはしない。

D169：研究用の資金解放は、固定した現物営業日calendarを決済日のproxyとしてT+2を算定し、さらにT+3の09:00 JSTまで再投資を待つ共通仮定を結果前に固定する。受渡し日、資金解放時刻、本人の口座余力を分け、`broker_verified=false`を維持する。全暦日・元データ版を認証し、欠落日・将来末尾不足・時刻変更は補正しない。既存の状態付きNAVへcalendar IDと明示時刻を渡して照合する。詳細は[研究用資金解放](DAILY_NAV_EVALUATOR.md)。この規則の固定だけで企業行動/執行/PITや厳密な市場認証を成立させない。

D170：新しい市場NAV再生は`research_funding_receipt`を固定して入口で照合し、適用policyを結果へ記録する。過去の独立根拠を持つ明示入力は読取互換を保ち、新ルール適用済みへ読み替えない。保存済みbaselineとensembleの精度比較では重み・校正・期間境界を変更せず、ensembleの後半meta検証と全候補/baselineの対象を一致させる。前半を別記し、IC未定義や欠損を0へ補完しない。全seed/種類平均・安定性、四半期、日付を組にしたblock区間を私有保存し、費用込み/採用評価とは分ける。

## ChatGPTの入出力

初期方式は本人によるpromptコピー/共有と回答JSONの取込。既存のアカウント連携は任意経路として保持し、有料APIを必須にしない。手動方式のモデル/推論設定はChatGPT側で選び、実際に使われたモデルをアプリが確認できなければ不明のまま残す。

入力は新規候補上位20＋順位外を含む全保有、5/20日それぞれの予測と意味/単位、既知の不確実性/リスク、口座別株数・資金・設定制約、予測/データ時刻・モデル版・口座snapshot IDを束ねる。5/20日を根拠なく加算せず、不明な確信度を作らない。肯定/反対の根拠を自由に調べ、与えた数値への同調を求めない。

回答は入力snapshot ID、根拠時点、銘柄、口座alias、目標保有株数、理由と出典を検証可能にする。売買差分はアプリが計算する。不正JSON（重複key/非有限値を含む）、古い/異なるsnapshot、重複/対象外銘柄、不明口座、単元・資金/費用・数量・口座/設定リスク違反は理由付きで拒否する。補正して確定しない。取込は提案だけを別保存し、原予測・保有/現金/税・実約定を変更しない。
