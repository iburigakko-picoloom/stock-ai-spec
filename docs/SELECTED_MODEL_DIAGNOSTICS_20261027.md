# 3モデルの既存評価の再照合（2026-10-27）

## 判断に使える範囲

既存の開発用アウト・オブ・フォールド（OOF）評価を再整理した。5日CatBoost値予測、20日CatBoost値予測、20日LightGBM順位のいずれも、評価できた行では平均順位相関が正だった。一方で期間によるばらつきがあり、値予測の誤差も残る。**正式採用の根拠にはまだ不足するため、採用判断はHOLDのまま。**

この数値は開発期間の分割学習による保存済み予測の診断であり、後に全学習入力から作られた配備用seed 17モデルそのものの将来成績ではない。評価対象はラベルと各モデルの保存予測がそろった行に限られる。過去の実受領時刻の証明不足、未来のラベルを使った対象行の選択、欠落予測や当時の全対象の不足があるため、当時実際に投資可能だった全銘柄の成績や、将来の運用成績とはみなせない。最終holdoutは使用していない。
