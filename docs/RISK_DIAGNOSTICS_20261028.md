# 株数判定に必要なリスク予測の既存診断（2026-10-28）

現在の3モデルは5日値予測、20日値予測、20日順位であり、株数エンジンの必要とする下落確率や下側分位点を出力しない。旧研究に残るリスク候補がすぐ追加できるか、保存済み開発診断を調べた。**この結果を採用済みリスクモデルや正式な株数提案に使うことはできない。**

元の5日・20日18構成の研究には、それぞれ回帰・順位とは別に、下落確率と下側分位点の予測が保存されている。今回、20日のCatBoost・LightGBM・XGBoost各3 seedの診断を、固定された共通採点集合について照合した。これは現在アプリで使う3本の出力ではなく、別の候補headの過去の開発評価である。

| 指標 | 保存済み診断 |
|---|---|
| 評価可能行 | 69,255行。予測可能集合には別途80行の予測欠落がある |
| 大幅下落の定義 | 予測対象期間末のリターンが -8%以下。保有中の最大下落ではない |
| 観測された大幅下落の割合 | 5.60% |
| 9候補の平均予測確率 | 11.45〜12.34% |
| 9候補のBrier score | 0.05856〜0.06205。小さいほど良い |
| 参考：同じ評価集合の発生率を事後的に固定値としたBrier | 0.05289。実際の予測時に未来の発生率は使えないため、配備可能な基準モデルではない |
| 10%下側分位点を実績が下回った割合 | 5.18〜6.68%。本診断では名目10%より低い |

この比較では9候補とも事後的な定数参考値よりBrierが大きい。予測確率の平均も発生率より高いが、これらだけで各日の精度や将来の校正を断定できない。いずれも再校正していない `RAW_NO_REFIT` の保存結果。分位点の頻度は対象行をまとめた値で、独立な日別ブロックに基づく不確実性を示さない。

全候補とも将来ラベルと保存予測が揃った条件付き集合であり、当時の実受領時刻の証明不足と対象選択の偏りがある。必要な予測も全件揃っていない。許容基準は、事前固定した学習期間の発生率・分位点との比較、時点に沿った校正、日別ブロックによる検証、費用・税を含むHOLD比較と別の最終検証が必要。現行の出力に仮のリスク値を埋めたり、評価前の候補headを付け足したりして株数提案を有効化しない。

照合には [確認スクリプト](../scripts/review_development_risk.py)を使用し、保存receipt・CSVと各9候補の元診断のハッシュ、対象行、条件、指標の一致を確認した。生データからの再学習・再予測・校正・未使用holdoutの読取は行っていない。詳細は私有 `.demo-artifacts/completion-20261021/risk-review-20261028.json`。
