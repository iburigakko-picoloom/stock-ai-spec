# Android版の完成条件

2026-10-17。本人指示をまとめた実装・受入票。実際の検証証拠がそろうまで未完とする。

## 利用の流れ

本人用モデルを一度取り込み、口座・保有・資金・費用・税と初回台帳を確認した後、必要なJ-Quants V2 APIキーを入力して「開始」。端末で初期履歴の取得、特徴量、5/20日予測、HOLD比較、推奨株数保存まで進める。モバイル回線を許可し、毎営業日の自動差分更新と完了通知を提供する。大規模再学習はPC側、実注文は本人が行う。

## 固定した選択

- 新規候補は時価総額300億円以上、直近20営業日平均売買代金上位300社。同順位は銘柄コード順。全保有株は必ず残す。市場・業種の計算母集団を300社へ縮めない。
- ChatGPT調査は数値モデル上位20銘柄と全保有。ChatGPTログインによる本人の利用枠を使い、利用不能時に別料金APIへ切り替えない。利用可能モデルと対応する推論深度をアプリで指定する。
- 初段はモデル順位・期待リターン・売買Actionを見せず、銘柄と判定時点から公開情報を調べる。その後に数値予測と照合。7観点は最低限で、追加論点、反対材料、情報不足を認める。
- ChatGPTの判断・根拠は数値提案と併記し、原予測、候補選定、株数を自動で書き換えない。調査時刻と11:30の数値入力締切を分ける。
- APIキー、OAuth資格情報、口座残高はAI調査へ送らない。OAuth資格情報はAndroid Keystoreで暗号化し、バックアップ・JSへの読出し・公開Git・ログから除外する。
- ホームは処理状況、今日の提案、次の操作。詳しい情報は詳細画面・折りたたみへ。タップ対象48px以上、隣接操作の間隔12px以上。削除・復元等を通常操作から離す。
