# Android版の完成条件

2026-10-17。本人指示をまとめた実装・受入票。実際の検証証拠がそろうまで未完とする。

## 利用の流れ

本人用モデルを一度取り込み、口座・保有・資金・費用・税と初回台帳を確認した後、必要なJ-Quants V2 APIキーを入力して「開始」。端末で初期履歴の取得、特徴量、5/20日予測、HOLD比較、推奨株数保存まで進める。モバイル回線を許可し、毎営業日の自動差分更新と完了通知を提供する。大規模再学習はPC側、実注文は本人が行う。

## 固定した選択

- 新規候補は時価総額300億円以上、直近20営業日平均売買代金上位300社。同順位は銘柄コード順。全保有株は必ず残す。市場・業種の計算母集団を300社へ縮めない。
- ChatGPT調査は数値モデル上位20銘柄と全保有。ChatGPTログインによる本人の利用枠を使い、利用不能時に別料金APIへ切り替えない。利用可能モデルと対応する推論深度をアプリで指定する。
- 初段はモデル順位・期待リターン・売買Actionを見せず、銘柄と判定時点から公開情報を調べる。その後に数値予測と照合。7観点は最低限で、追加論点、反対材料、情報不足を認める。
- ChatGPTの判断・根拠は数値提案と併記し、原予測、候補選定、株数を自動で書き換えない。調査時刻と11:30の数値入力締切を分ける。
- APIキー、OAuth資格情報、口座残高はAI調査へ送らない。OAuth資格情報はAndroid Keystoreで暗号化し、バックアップ・JSへの読出し・公開Git・ログから除外する。
- ホームは処理状況、今日の提案、次の操作。詳しい情報は詳細画面・折りたたみへ。タップ対象48px以上、隣接操作の間隔12px以上。削除・復元等を通常操作から離す。

正常な無売買・全現金を成功結果とする。古い結果の時刻を新しく見せず、数値完了と調査未完を区別する。OSによる実行遅延を表示し、締切後の受領データを11:30へ遡及させない。採用モデル0件、API403、未入力、実機未確認を試験成功で解消済みと数えない。これらが残る間は「APIだけで実用開始できる」と判定しない。

全市場の容量はD126で検証を追加。旧形式は合成5,000銘柄・90営業日のcheckpointでnative payload上限を超えたため、原データと正規化byte/hashを保つcolumn形式へ変更した。300営業日・150万株価行でpayload55,754,616文字とPC復元がpassし、旧450batchの凍結内容も一致。PCのPIT読込ピークは約3.63GB→約2.16GB。native暗号化の毎回commit、全特徴量計算、Xiaomi性能、150万行guardを超える継続履歴の受入は別に残る。市場母集団を上位300社へ縮めて容量問題を回避しない。

全市場の最新特徴量はD127で保持量と財務参照を見直した。V0/V1/V2の全期間末尾との完全一致、41/51列の既存PC参照を維持する。直接計算だけでは全量mobile JSON変換の容量問題を捕捉できなかったため、D129で出所ID確定後の必要列DataFrameと同じJSON精度の列変換へ接続し、source hashも同じbyte列を分割して計算する。CIは5,000銘柄・300営業日の合成初回受領からアプリ入力変換/特徴量計算までを確認する。実forecast、native暗号化commitとXiaomiの完走は別に残る。D128でportable backupの保存前にも既存復元容量を確認する。

D130では日ごとの全出所照合と必要列の保持へ進め、150万行の元readerを必要としないアプリ経路を追加。型・全ID・全履歴・市場/業種母集団を保ち、合成5,000銘柄/520営業日・260万行の保存/復元と5/20日特徴量をPCで確認した。特徴量581.23秒・ピーク3,384,135,680bytes、capsule96,870,524文字で既存予算内。CIも520日へ拡大する。モデルを含む実forecast、native毎回commit、Xiaomi、さらに長い継続履歴は未完のまま残す。

## 追加で確認する利用設計

- 初回確認後の保有・残高の正本と再確認頻度を揃える。現状は手入力と台帳の一致・72時間以内が計算条件。台帳の継続利用を選ぶ場合は、約定・入出金・税・NISA残枠の履歴を連動し、手入力を勝手に再確認済みにしない。
- 数値モデルとChatGPTが食い違った場合、一致を強制せず、それぞれの根拠と情報時点を確認できること。
- 同一条件の自動再実行を抑止し、明示的な再調査やモデル・推論量変更は別履歴として保存すること。初期案は営業日ごとに1回の自動調査。
- 上限、検索不可、通信中断、認証失効を区別し、数値計算済み・調査待ちを表示すること。無料の自動モデル変更で判断条件を変えないこと。
- 公開時刻が確認できない出典は不明のまま残すこと。引用URLだけで11:30当時の利用可能性が立証されたと扱わないこと。
- モデル・推論量・プロンプト版・調査日時・根拠を残し、後日その判断が役立ったかを検証できること。ChatGPTを加えた効果は未検証。
- ホームは要点、銘柄詳細は判断の食い違いと出典、設定はモデル等に分け、画面幅と文字拡大で操作間隔を実測すること。
